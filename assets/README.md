# Asset policy and art direction

The kit contains no finished art assets. Use graybox primitives first.

## Visual direction
Stylized-realistic fantasy with crisp forms, lush layered vegetation, varied terrain materials, dramatic skies, wet surfaces, atmospheric depth, and readable elemental effects. Keep player and boss silhouettes distinct from backgrounds.

## Asset ledger
For every imported asset, record:
- Asset name / filename
- Source URL or creator
- License and attribution requirement
- Modifications
- Intended use

See `ASSET_LEDGER.md`.
